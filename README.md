# UAS Sistem Pakar Hybrid

Proyek ini merupakan tugas UAS mata kuliah Sistem Pakar yang mengimplementasikan
sistem hybrid antara Neural Network dan Sistem Pakar berbasis aturan
untuk diagnosis penyakit sederhana.

## Teknologi
- Python
- Scikit-learn
- Google Colab

## dataset
= Disease_symptom_and_patient_profile_dataset.csv (Kaggle)
    
## Fitur
- Prediksi penyakit menggunakan Neural Network
- Validasi dan koreksi menggunakan sistem pakar
- Perbandingan hasil dengan dan tanpa sistem pakar

## Cara Menjalankan
Buka file notebook di Google Colab dan jalankan seluruh cell.
